# Survey Form Practice 🐾

This repository contains a simple `index.html` survey form for fur parents, built as part of my **Responsive Web Design Certification** on freeCodeCamp using pure HTML.

## What I Learned & Key Takeaways

* **Semantic HTML Forms:** Practiced structuring accessible forms using `<fieldset>`, `<legend>`, `<label>`, and semantic input types (`text`, `email`, `number`, `radio`, `checkbox`, `<select>`, and `<textarea>`).
* **Built-in Validation:** Applied native HTML attributes like `required`, `min`, and `max` to enforce basic client-side validation without JavaScript.
* **Independent Problem-Solving:** Worked through confusing project instructions on my own to ensure all freeCodeCamp user stories and IDs matched properly.
